# Examples

`scene_batch_example.json` demonstrates the bulk-import schema described in
the main [README](../README.md#bulk-import-from-json-optional-llm-friendly).

It references a placeholder image, `scene1_start.png`, which is **not**
included in this repository — replace it with a path to your own image (or
edit the first scene to drop `start_image` and use `t2v` instead) before
importing it.
